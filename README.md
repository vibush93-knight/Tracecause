# TraceCause

AI-powered outcome-first investigation platform that discovers the chain of events behind real-world outcomes using multiple AI agents.

## Features

- 🔍 Research Agent
- 📑 Evidence Collection
- 🧠 Causality Analysis
- ✅ Verification Agent
- 📈 Timeline Visualization
- 🌐 Interactive Investigation Dashboard
- ⚡ TrueForge Agent Harness Integration

## Tech Stack

- React
- TypeScript
- Vite
- CSS
- TrueForge

## Installation

```bash
git clone https://github.com/vibush93-knight/Tracecause.git
cd Tracecause
npm install
npm run dev
```
